King Power · Smart POS · Windows cashier station

A desktop station built for the counter,
not a stretched handheld.

Seventeen screens at 1920×1080, rebuilt from smart-pos-mobile. Same domain objects as the Ionic app — Buying / Basket tabs, Total · Grand · Cash-D · Net Pay, Take/Collect per line, freeze & lock-discount flags, currency rate on the bill — re-laid out for a wide screen, a barcode gun, a mouse and a keyboard.

Assumption
The scan field always owns focus. Everything else is reachable by F-key so a cashier never has to find the mouse mid-sale.
Assumption
One line item = one table row. The handheld's five-row stacked card becomes columns, so 14 lines fit without scrolling.
Kept from today
KP gold hierarchy, the four-line totals block, warning flags for CITES / serial-required lines, and the Delivery / Pre-order mode colours (#165FA9, #BF4D0D).
Changed
Net Pay is the single largest number on screen. Rate and secondary currency move to the bill header instead of the toolbar.
